Como adicionar o teclado (hebraico)

macOS
Ajustes do Sistema → Teclado → Entrada de Texto → Editar… → “+” → Hebraico → “Hebraico – PC” → Adicionar. Troque de teclado com Control + Espaço ou a tecla 🌐.
Windows
Configurações → Hora e idioma → Idioma e região → Adicionar um idioma → Hebraico. O teclado que o Windows sugere serve: as letras ficam nos mesmos lugares. Troque de teclado com Windows + Espaço.
Linux
GNOME: Configurações → Teclado → Fontes de entrada → “+” → Hebraico. Troque de teclado com Super + Espaço.
